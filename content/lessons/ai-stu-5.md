## 这节课你会...

把一场活动从头到尾那些杂事拆成几张卡片存起来，下次换个名字就能用。

## 策划案先搭骨架

一份策划案要回答五件事：为什么要办、当天干什么、谁负责什么、要花多少钱、出事了怎么办。

直接问"帮我写份策划案"，它只能给你一堆"丰富校园文化生活"。因为你没告诉它活动是什么。

```
我要办【活动名】，面向【谁】，预计【多少人】参加，
时间是【日期和时间】，地点在【地点】，经费大概【多少钱】。
我们社团现在有【几个人】能用。

帮我写一份策划案，分成五块：
活动目标（说清楚办完能达到什么效果）、
当天流程（精确到分钟，几点到几点做什么）、
人员分工（需要几个人，各自负责什么，写清谁盯哪一块）、
预算明细（每一项多少钱，加起来别超我给的数）、
可能出的问题和对应办法（至少三条）。

语气按给学生干部看的来写，别用官腔。
```

流程那一块最有用。你会发现它排出来的时间线里，有些环节根本没人干，比如"签到谁管""话筒谁看着"。

## 通知怎么写才没人追问

群里发一条通知，底下必有几个"什么意思""几点来着"。问题基本都出在缺件。

谁、什么时候、在哪、做什么、找谁问。五样缺一样，就会有人来问你。

```
帮我写一则班级通知，内容是：【把事情说清楚，先别管好不好听】。

要求：两百字以内，前两行就写清时间和地点，
中间说清楚要带什么、要做什么，
结尾写联系人，名字是【你的名字】，微信是【微信号】。

语气正常一点，别像红头文件。
```

写完自己用手机读一遍。读着别扭就让它再改一版，加一句"再口语一点，像我在群里说话那样"。

## 拉人参加，给三种人写三种话

同一件事，跟室友说、跟同班同学说、跟不太熟的人说，说法完全不一样。

室友那句可以随便："周六下午来帮个忙，管饭。"

同班同学要讲好处："来一次算一次志愿时长，两个小时。"

不熟的人要把成本说清楚："周六下午两点到四点，在体育馆，就是搬东西和签到，不用准备别的。"

```
我要拉人参加【活动名】，时间【时间】，地点【地点】，
参加的人能拿到【好处 / 志愿时长 / 小礼品】。

帮我写三段话术，分别发给：我的室友、同班同学、不太熟的同学。
每段不超过三句，说清楚时间、地点、要花多久、能拿什么。
别用"诚邀""共襄盛举"这种词。
```

## 海报底图的提示词

海报上那些字（时间、地点、社团名）自己加，让 AI 只画底图。

```
帮我写一段画图提示词，用来生成一张【活动名】的海报底图。

主体是【画面内容，比如几个人在操场上拍照】，
风格是【简约 / 复古 / 手绘 / 扁平插画】，
主色调是【颜色】，整体明亮一点。

画面上下各留出一块空白，我要自己往上加字。
画面里不要出现任何文字。
```

"不要出现文字"这一句一定要加。不然图上会冒出一堆拼错的英文和歪掉的字，改都改不掉。

生成出来之后，把字加在白底或半透明色块上，别直接压在花花绿绿的画面里，远处根本看不清。

## 存成四张卡片

一场活动至少存四张卡片：策划案、通知、拉人话术、海报提示词。

存到手机备忘录或者微信收藏里，标题写清楚是干什么用的，比如"社团招新-通知"。下次办活动，翻出来改几个字，十分钟能搞定一大半。

办完别忘了让它复盘：

```
这次活动办完了，实际情况是：【哪里顺利、哪里出问题、来了多少人、花了多少钱】。
帮我写一段简短的复盘，说清楚这次哪里做得好、下次要改什么。
别写成自我表扬，有问题的部分直接写。
```

> 记住这一句：通知写全五件事，海报留出空白。省下来的时间，才是你自己的。
