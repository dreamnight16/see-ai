## 这节课你会...

把难开口的话写出来，语气不卑不亢。

---

## 先要三种语气，你来挑

职场沟通难的不是内容，是分寸。太软显得好欺负，太硬又得罪人。

所以别让它写一版等你改。直接要三版。

```
我要给合作方发消息，催一份拖了 10 天的物料清单，下周就要用。
请给我三个版本，每个都不超过 150 字：
A 客气版，给对方留足面子，但把时间点说死
B 中性版，公事公办，只讲事实和截止时间
C 强硬版，明确说清后果，但不带情绪
三个版本都别用"麻烦您""拜托了"这种过度客气的说法。
```

三版摆在一起，你一眼就知道该用哪版。把它当成试衣服，别指望一次就穿上。很多时候你真正需要的是 B，但自己动手只会写成 A。

## 向上汇报，结论先行

给领导发消息，第一句就给结论。他没耐心看到第三段。

顺序是：结论、依据、需要他做什么。

```
帮我写一条发给部门总监的汇报消息，结论先行。
背景：新客户试用转化率这个月是 12%，上个月是 18%。
初步判断是试用账号的激活流程太长，平均要走 6 步。
我想申请开发资源把它简化到 3 步，大约占用一名开发一周时间。
先给结论，再给依据，末尾写清我请他做什么决定。总长 200 字以内。
```

它常犯的毛病是铺垫太长，一段话说了三句还没进正题。看到"为了进一步提升用户体验"这种开头，直接让它删掉重写。

## 拒绝和道歉，别让它替你认错

拒绝一件事的公式是：先给结论，再说原因，再给替代方案。只说一句"我做不了"最伤人。

道歉要看责任在不在你。不属于你的锅，别让它写"非常抱歉，都是我的问题"，那等于你自己签字认了。

```
帮我回复这封邮件，内容是拒绝对方这周内出终稿的要求。
事实是：原始数据对方迟交了 5 天，评审至少需要 3 个工作日。
不要替我道歉，不要承认是我方延误。
语气专业，给出一个新的、可行的交付时间。
```

## 一句不能忘的底线

不要让它替你做承诺。

价格、折扣、工期、赔偿、合同条款、能不能破例，这些它一概不知道，但它会很流畅地替你答应下来。

所以发出去之前，把这几个词挨个搜一遍：可以、没问题、我们保证、一定、随时、任何时间。搜到就停下来想一想，这是不是你能答应的。含糊的承诺发出去，回头要么你自己补窟窿，要么对方觉得你不算数。

涉及金额和条款的邮件也一样，AI 只帮你顺语气，条件必须你亲自写。

## 发出去之前做一遍减法

难开口的话，写长了反而更虚。写完让它砍一遍：

```
这段话我想表达的意思都在，但读起来太绕了。
请在不改变立场的前提下，把它删到原来的一半长度。
删掉的必须是修饰和铺垫，事实和请求一条都不能少。
```

短下来的那版通常更像你自己说的话。你真坐在对方面前，也不会一口气讲三段客套。

> 记住这一句：先要三种语气再挑，能答应什么，只有你自己知道。
