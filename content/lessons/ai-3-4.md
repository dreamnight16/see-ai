## 这节课你会...

把一小时的会，变成三行明确的行动项。

---

## 先把录音变成文字

手机和会议软件大多自带录音转文字。转出来是一大坨，没有分段，错别字也不少，看着头疼。

先让 AI 收拾干净：

```
下面是一段会议录音转出来的文字，没有分段，可能有不少错别字和同音字错误。
请先做三件事：断句分段、改掉明显的错别字、把不同说话人分开标成"说话人1 说话人2"。
不要总结，不要删减内容。
```

"不要总结"这句一定要加。它默认以为你只要个大概，其实你后面还要拿原文去查。不然它会顺手把一半内容吃掉，你后面就没东西可分析了。

## 第二遍才要结构

文字干净之后，再单独发一次，这次要结果。

```
基于上面的会议记录，整理成四块：
1. 达成的结论：谁定的，定的是什么
2. 有分歧的地方：谁和谁意见不一致，卡在哪一点
3. 待办事项：每条写清做什么、谁负责、什么时候交
4. 下次要接着讨论的问题
待办事项必须能对上原文。原文里没出现的负责人和日期，不要自己补。
```

"不要自己补"这句很重要。不写的话，它会好心替你安排一个负责人，而那个人是它编的。

## 追问哪些事没有结论

开完会最怕的不是没记录，是记了一堆讨论，真正要拍板的事还悬着。

让它专门找一遍：

```
回头再看一遍原文，列出所有提出了但没有形成结论的问题。
每条写清：谁提的、当时为什么没定下来、需要谁来拍板。
```

这份清单往往比会议纪要本身更有用。会开完不算完，事情定下来才算完。下次开会开场先过一遍它。

## 纪要怎么让人看得懂

纪要不是流水账。看的人只想知道三件事：定了什么、我要做什么、什么时候交。

所以格式上，结论和待办放最前面，讨论过程放后面，甚至可以只留一句"详细讨论见附件"。

发给不同的人也要分开。给领导的那份重点在结论和风险，给执行同事的那份重点在待办和截止日期。

还有一件事值得多花两分钟：把待办的截止日期直接换算成具体日子。别写"下周内"，写成"周四下班前"。模糊的时间词到了执行层，基本等于没有期限。

```
把上面这份待办事项里的时间说法，全部换成具体的日期和时点。
今天是 3 月 12 日星期三。保持原本的语气，不要改动任何事情的内容。
```

## 有些会别录

涉及人事处理、薪酬调整、客户纠纷、还没公开的收购或者人事变动的会议，不要上传录音，也不要粘进任何在线 AI。这类内容一旦流出去，追责的时候很难说清是谁的问题。

另外，录音在很多场合要先征得参会人同意，这跟 AI 没关系，是本来就该注意的事。

真要用 AI 帮忙，把手写要点里的真实姓名换成代号，去掉具体金额，只让它帮你归类、排版、检查有没有漏项。

> 记住这一句：录音转文字之后分两次问，一次要干净的文字，一次要结论和待办。
