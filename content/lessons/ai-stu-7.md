## 这节课你会...

从"不知道讲什么"到"能站上去讲十分钟不慌"。

## 先定一句话

上台之前，先写下这一句话：我想让同学记住＿＿＿。

写不出这一句就别做 PPT。做出来一定是资料的堆砌，你自己讲到第三页就不知道自己要说啥了。

```
我要在【课程名】课上做一次【几分钟】的汇报，题目是【题目】。
我的专业是【专业】。

请你先不要给我写任何内容。
先帮我想出 3 个可能的"一句话核心观点"，
每个都用一句话说清楚，再告诉我：
哪个最好讲、哪个最容易翻车、哪个适合我这种没什么经验的人。
```

挑一个，然后后面所有东西都围着它转。跟它无关的材料，再好看也删掉。

## 大纲怎么排

十分钟的汇报，三到五块就够了。一个常见的排法是：

为什么讲这个（半分钟，把同学的注意力抓住）
现在是什么情况（两分钟，摆事实）
我的观点是什么（一句话）
证据在哪（三到四分钟，例子、数据、案例）
所以呢（一分钟，落回一句话）

```
我的核心观点是：【那一句话】。
我手上有这些材料：【把资料、案例、数据列出来】。
汇报时间是【几分钟】。

帮我把这些材料排成大纲，每部分标上大概讲几分钟，
并告诉我哪些材料可以砍掉，砍完还剩【几分钟】就够。
```

每页只放一句话。新手最容易犯的错，是把一大段话塞进一页 PPT，然后站在台上照着念。

一页一个意思，一行字。同学抬头看一眼就懂，低头就能听你说。

真需要讲数据的，就放一张图，别放表格。表格是给自己看的，图是给台下看的。

## 讲稿要写成能念出来的话

书面语念出来会打结。你可以先把想说的写下来，再让它改成口语：

```
下面是我的讲稿：【贴上来】。
我要站在台上念出来，请你帮我改成口语：
句子拆短，去掉书面词，把拗口的地方换成顺口的说法。

保留我原来的意思，别加新内容。
改完之后标出哪几句最容易念错，我提前练。
```

写完之后出声念一遍，掐表。

超时了就删例子，别删观点。例子少讲一个没人发现，观点没了整个汇报就散了。

宁可短一分钟，也别超时。超时的时候老师可能会打断你，你一慌，准备好的结尾就讲不出来了。一般按实际时间的九成准备比较稳。

## 让它当最挑剔的那个同学

```
你现在是坐在第一排、不太好说话的同学，听完了我的汇报。
这是我的讲稿：【贴上来】。

请挑 5 个毛病，每个都用提问的方式说出来：
哪里你没听懂、哪里你不同意、哪里听起来像空话、
哪里你怀疑数据是编的。

直接问，不要给答案，我要自己回答。
```

这些问题的好处是，你能提前想一遍台下会怎么问。真被问到的时候，你至少不慌。

## 上台前念一遍，出声念

别默读。默读的时候脑子会自动跳过磕绊的地方。

出声念两遍，你会发现有些句子舌头绕不过来，有些地方你自己念着都心虚。这些地方必须改，改完再念一遍基本就顺了。

念的时候站着念，别坐着。坐着念和站着讲是两回事。

还有个笨办法很管用：把讲稿念给室友听一遍。你会发现自己在某几句话上总要多看一眼稿子，那几句就是没写顺的地方。室友听不懂的地方，台下大概率也听不懂，回去把那几句改成大白话。

上台前把第一句背下来。开场那一句说利索了，后面整个人就稳了。

> 记住这一句：一页一句话，讲稿要能念出来。念不顺的地方，就是讲不清的地方。
