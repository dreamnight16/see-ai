## 这节课你会...

拿到一个能反复用的提问公式。以后不用每次对着输入框发呆，想清楚"这句话该怎么说"。

---

## 先看一件大家都干过的事

你打开对话框，敲下一行字：

```
帮我写一段自我介绍
```

回车。出来的大概是：本人性格开朗，工作认真负责，具有较强的团队协作精神……

这段话挑不出毛病，但给谁看都行，等于白写。你改成"帮我写一段面试用的自我介绍"，出来的还是这一套。

问题不在 AI 笨，在你没说清楚。它手里只有你给的这一句话，剩下的全靠猜。它不知道你是去面试超市店长还是去面试会计，不知道你干了六年还是刚毕业，也不知道你平时怎么说话。猜出来的东西，只能是最大路货的那种。

---

## 四件套：角色、任务、要求、例子

| 四件套 | 它是干什么的 | 少了它会怎样 |
|---|---|---|
| 角色 | 给它一个身份和看问题的角度 | 它会用百科全书的口气，跟你隔着一层 |
| 任务 | 说清要它交出来什么 | 给你一堆分析，就是不给你要的那件东西 |
| 要求 | 字数、场合、语气、给谁看、不许出现什么词 | 出来又长又正式，你还得自己改半小时 |
| 例子 | 给它一段"照着这个感觉写" | 语气不对，像换了个人写的 |

这四样里，**例子最容易被忽略，效果却最猛**。你写不出一段好文案，但你一定见过一段让你觉得"就是这个味儿"的话。把它贴过去，比说十句"写得亲切一点"都管用。

## 同一个任务，三个版本

**第一版，光有任务：**

```
帮我写一段自我介绍
```

结果：谁都能用的一段废话。

**第二版，加了角色和要求：**

```
你是一个做了十年招聘的 HR。
帮我写一段面试用的自我介绍，三百字左右，口语一点。
```

结果：短了，也像人话了。但还是不知道你是谁，内容空。

**第三版，四件套齐了：**

```
你是一个做了十年招聘的 HR，看过上万份简历。

任务：帮我写一段面试自我介绍。

要求：
- 用在社区超市招店长的面试上
- 我做过六年超市理货和收银，带过五个人的班
- 两分钟左右能说完，三百字上下
- 口语，别用"闭环""抓手"这种词
- 开头三句就说清我能给店里带来什么

例子（我想要这个感觉）：
"我在这个片区干了六年，附近三个小区常来的顾客我基本都脸熟。"
```

你把这版发出去，再回头看第一版，就知道差别在哪了。

## 不用背，抄成一条备忘录

公式就四行，存在手机备忘录里，或者微信收藏里。用的时候照着填，填完删掉括号。

```
你是谁：（比如：一个有十年经验的初中班主任）
要你干什么：（比如：帮我改一封给家长的通知）
有什么限制：（比如：三百字以内，语气平和，别像公文）
照着什么样写：（贴一段你觉得好的话）
```

填不满也别慌。四条里能写清三条，结果就已经好很多。

---

## 公式也有不管用的时候

四件套解决的是"你没说清楚"，解决不了"它根本不知道"。

你店里上周卖了多少斤苹果、你客户昨天在电话里怎么抱怨的、你老板开会时的原话，这些它脑子里没有。你问它，它不会说"我不知道"，它会编一个听起来很像那么回事的答案给你。这才是最容易踩的坑。

分界线很简单：**这件事是不是只发生在你身边？** 是的话，你得先告诉它；它不知道的部分，宁可你自己填进去，也不要让它猜。

---

> 记住这一句：你写的不叫问题，叫说明书。角色、任务、要求、例子，四样凑齐，它才不用猜。
