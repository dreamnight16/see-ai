## 这节课你会...

把 AI 放在语言学习最合适的位置上：陪练，而不是代写。

## 口语陪练：让它只说你会的词

口语是它最合适的用处，因为口语最缺的就是一个随时有空、不笑话你的搭子。

关键在定规则。不定规则，它会甩给你一大段又长又难的英文，你根本接不上。

```
你现在陪我练英语口语，话题是【话题，比如点餐 / 面试 / 旅行】。

规则：
1. 只用我大概认识的高中词汇，句子短一点
2. 每次先正常用英语回我一句，别长篇大论
3. 再用中文指出我刚才哪里说错了、正确说法是什么
4. 我卡住说不出来的时候，给我一个能用的句型

现在开始，你先说第一句。
```

练完之后让它总结：

```
把刚才这段对话里我犯的错总结一下，
按语法、词汇、表达习惯分成三类，
每类给我两三个最常犯的例子。别超过一页。
```

## 翻译作业：先自己写，再对照

直接让它翻译，你什么都学不到。正确的顺序是：你翻完，再让它对照原文挑错。

```
原文是：【贴英文原文】。
下面是我自己翻的：【贴你的翻译】。

请你不要说"翻译得很好"，直接逐句对照，指出：
哪里意思翻错了、哪里语法有问题、哪里中文读起来不像中文、
哪里可以换一个更地道的说法。

每条都给出改法。不要重写整篇，我自己改。
```

自己改完，印象比看十遍范文都深。

## 作文批改要它先说优点

一上来就让它挑错，你会被打击得不想写。让批改有点顺序：

```
请批改我下面这篇作文。按【四六级 / 考研 / 雅思】的标准来。

先说三条我写得好的地方，具体到句子。
再说问题，按重要程度排，只挑最影响得分的三处，
说清楚为什么扣分、怎么改。

末尾给我一个分数区间。

不要帮我重写一篇完整范文，我自己改。
```

那句"别重写范文"很重要。它一重写，你多半就直接抄它那篇了，下次还是不会写。

## 四六级：听力和阅读这么练

听力：找一段真题材料，听写下来，再让它对照。听漏的词它给你标出来，你就知道自己是反应不过来还是压根不认识。

```
这是四级听力真题的原文：【贴原文】。
这是我的听写：【贴我写下来的】。

请逐词对照，标出我漏掉的、写错的词，
然后告诉我：扣掉的这些是关键词还是虚词。
关键词漏得多的话，说明我听力该从哪方面补。
```

阅读：做完题，把错题的原文段落贴进去。

```
我在做四级阅读，这道题我选了【你的答案】，正确答案是【正确答案】。
原文段落我贴在下面：【贴段落】。

请指出原文里哪一句话能推出正确答案，
我当时是因为把哪一句话理解偏了才选错。
说清楚就行，别翻译整段。
```

考研专业课的自测也是同一个套路。把要背的定义和要点粘进去，让它出填空题和简答题。答完再对，错的地方隔一天再问一遍。

```
下面是我考研专业课【科目名】要背的内容：【贴上来】。

请你出 20 道题考我：10 道填空、10 道简答，
覆盖上面的内容，别只考开头那几句。
出完先别给答案，等我答完再一起对。
```

它帮你查漏，但记住那些字还得靠你自己念出声。

## 单词别交给它

它给你排的词表，你记不住。不是词表不好，是你跳过了那个反复看到烦的过程。

单词得自己刷。它能帮的是另外几件事：用你给的一个词造五个不同场景的句子、解释两个近义词到底差在哪、随机抽查你。

> 记住这一句：先自己写、先说、先背，再让它挑错。顺序反了，你什么都没学会。
