## 这节课你会...

把手机里那个只会陪你闲聊的豆包，变成能替你干活的工具。动作只有一个：把"问它"改成"派活给它"。

## 你平时是这么用它的

问天气、问食堂哪家好吃、让它写两句生日祝福、半夜睡不着跟它扯两句。

这些用法都没错，但你只用到了一成。聊天的时候，你在等它给你一个说法，说得好不好你也就是看看，看完就划走了。干活不一样：你手里有一件真事，你要它交出一份能直接发出去、直接交上去的东西。

区别就藏在这里。聊天是你把问题丢过去，干活是你把情况和目标一起丢过去。

## 同一件事，两种问法

先看聊天式：

"帮我写个社团招新文案。"

它回你一段"青春正当时，欢迎加入我们"的东西，谁都能用，发出去没人看。

再看干活式：

"我们摄影社，9 月 20 号在二食堂门口招新。去年招了 30 个人，管不过来，今年想控制在 15 个以内。文案发在学院公众号，两百字以内，别太官方，末尾带上报名方式。"

这个版本里有哪些信息？你是谁、什么时候、在哪、给谁看、多长、什么语气、想要什么效果。它不用猜，就编不出空话。

**它答得差，八成不是它笨，是你给的信息太少。** 这条规律从第一句话开始就成立。

## 开口先说这四样

我的情况、我要什么、材料在哪儿、要什么格式。

一个可以直接套的句式：

"我是【你的身份】，现在要【做一件什么事】。相关的东西在下面：【粘进去】。给我【几版 / 多少字 / 什么语气】，是给【谁】看的。"

把这件事当成给同学发微信派活。你不会跟同学说"帮我弄一下那个"，你会说清楚什么时候要、要什么样。对它也一样。

## 五段可以直接照着发的开场

选课：

```
我是【专业】大【几】的学生，这学期要选【几】门课。
下面是我们专业的培养方案和几门课的介绍：【粘上】。
我的情况是：想保研，怕挂科，周一到周三下午有社团活动。
帮我排一个选课组合，告诉我每门课的难度大概什么水平、
哪几门凑在一起会累死、哪门可以先放一放。给两个方案，一个稳的，一个拼的。
```

日程：

```
把我下面这些事整理成一张时间表：【把作业截止日、考试周、社团活动、兼职时间乱着写进来】。
我不熬夜，晚上十一点前要睡。帮我看看哪几天会撞车，
哪个任务应该提前几天动手。用表格给我。
```

社团：

```
我是【社团名】的【职务】，我们【时间】要办【活动名】，
预计来【多少人】。帮我写三样东西：
一份给社员的动员话术、一份发在学院群里的拉人文案、一份当天的人员分工表。
语气按学生社团的来，别写得像公司开会。
```

找资料：

```
我要做一个关于【题目】的【课程作业 / 汇报】，我是【专业】的。
帮我列出这个题目可以从哪几个角度切入，
每个角度该搜什么关键词，以及哪里能找到靠谱的资料。
先不要给我结论，我自己去看。
```

写东西：

```
我要写一篇【多少字】的【课程论文 / 读书报告】，题目是【题目】。
我的观点是：【写一两句你自己的看法，多粗糙都行】。
先别写正文。帮我把这篇文章的结构列出来，
每一部分大概写多少字、要解决什么问题。我确认之后自己写。
```

这五段有个共同点：都交代了背景，都说清了要什么，都提了限制。你照这个套路改，什么场合都能用。

## 有几个坑提前说

它说得特别顺、特别自信的时候，你反而要留个心。数据、书名、政策条文这些，它编得非常像真的，用之前自己搜一下。

涉及你不想让别人知道的事（身份证号、家庭住址、别人的隐私），别往里粘。

它给的东西永远是初稿。初稿的价值是让你不用对着空白页发呆，不是让你直接交。

> 记住这一句：它不是陪你聊天的，是等你交活的。你交代得越具体，它越像个帮手。
