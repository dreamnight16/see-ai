## 这节课你会...

把课件和笔记喂给它，让它出题考你，而不是替你把答案整理好。

## 先喂料，再提要求

直接问"帮我总结一下这本书的重点"，它只能还给你一份谁都能用的东西。

顺序反过来：你先把材料倒进去。

材料是什么？课件截图、自己抄的笔记、老师上课反复强调的那几句、去年的真题题型。拍照片的时候把标题和页码拍清楚，别糊。

倒进去之后，再告诉它三件事：这是哪门课、考试是什么题型、你哪块最没底。

```
下面是我【课程名】的课件和笔记，还有老师说过的考试范围。
这门课期末是【闭卷 / 开卷】，题型有【名词解释、简答、计算、论述】。
我最没底的是【哪一章】。
先别急着总结，你先告诉我：这些内容里哪些是核心，哪些是边角料。
```

## 让它出题，不要让它总结

总结这东西看着很爽。读一遍，感觉都会了，合上书什么都没剩下。

出题不一样。你在答题，答不出来就是没会，它骗不了你。

```
请你根据上面这些内容出 15 道题：10 道简答、5 道选择，
难度按这门课期末的来。

出完先不要给答案，等我全部答完再一起对。
```

答完之后再开一段新对话对答案：

```
我答完了，下面是我的答案：【贴上来】。
你逐题判，答对的不用多说，
答错的告诉我错在哪个概念上，然后追问我一个更基础的问题，
看我到底是这个概念没懂，还是整个部分都没看。
语气直接一点，别安慰我。
```

错题要隔一天再问一遍。当场对完答案，你觉得自己懂了，其实是答案还在眼前。

隔一天，同样的题再问一次。答得上来说明真记住了，答不上来说明当时是靠提示。

这一步别省。省了的话，考试那天你会以为见过这道题，但就是想不起来。

错题还要分类。同一道题错两次，说明是概念没懂，得回去看那一段。错一次但第二天就会了，说明只是没背牢。这两类的复习方式不一样，前一类要重新理解，后一类多看两遍就够了。你可以直接把错题贴给它，让它帮你判断属于哪一类：

```
下面是我这几天的错题：【贴上来】。
帮我看看这些错题里，哪些是同一个概念没搞懂，
哪些只是记不牢。把属于同一个概念的归成一组，
告诉我这个概念到底是什么，以及它和我做对的那几道题有什么关系。
```

## "用我自己的话讲一遍"为什么不能省

这是整个复习里最容易被跳过、又最关键的一步。

```
下面这段是我笔记里的内容：【粘上】。
我现在用我自己的话讲一遍，你别打断我，听完再说。
我讲完之后，你告诉我：哪里讲错了、哪里漏了、哪里我其实是在背原话没真懂。
```

AI 讲得再清楚，那也是它的提纲。考场上能写出来的是你自己的话，不是它的。你讲一遍，卡壳的地方就是你没懂的地方，一眼就能看出来。

## 考前三天怎么排

第一天：把整本书的目录过一遍，标出三块最没把握的，先啃最没把握的那块。

第二天：啃第二块，加上做题。做题要计时，别一题想二十分钟。

第三天：只做题和看错题，不再看新东西。新东西会让前两天的白干。

顺序的道理很简单：怕的那块先解决，它最占你的心理空间。真到了考前一晚还在翻第一页，那种慌最要命。

还有一件小事：课件照片拍糊了、笔记缺了一页，这些都别硬凑。它看不见的东西，会按自己的理解补上，补出来的还挺像真的。缺哪块就回去补哪块，或者找同学要一份。

## 有些东西别让它代劳

公式推导和证明过程，自己推一遍。它写的步骤经常跳，你照着背，考场上跟不出来。

老师明确要求手写的部分，自己写。

要背下来的定义原文，以课本为准。它整理出来的定义和你考场上该写的不是一套话。

专业课的术语说法，课本怎么写就怎么记。

> 记住这一句：让它出题考你，别让它替你把答案整理好。看起来会了，是最危险的状态。
