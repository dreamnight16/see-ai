## 这节课你会...

从对着空白页发呆，到手里有一份能改、能讲的骨架。

## 分三步问，别一次要完

最没用的问法是"帮我做一份 PPT"。它会给你一堆漂亮但用不上的空话。

拆成三步走。

第一步，只要大纲。

```
我要在部门周会上讲 10 分钟，听众是同部门的 8 位同事和一位总监。
主题是我负责的客户回访项目。
先别写内容，只给我一份大纲：一共几页、每页讲什么、每页用一句话说清核心观点。
总页数控制在 8 页以内。
```

第二步，确认大纲，再要内容。

```
大纲可以，把第 3 页和第 5 页调换一下顺序。
现在按这份大纲，把每页的正文写出来，每页不超过 4 条，
每条不超过 20 个字，我是要往幻灯片上放的。
```

第三步才要讲稿。

```
现在给每页配一段口头讲稿，口语一点，一页大概说 40 秒。
我说话容易快，你写短句，我要能看着念。
```

分三步的好处是每一步你都能拦一下。一次性生成的东西，改起来比重做还慢。

## 每页一句话

判断一页该不该存在，就看你能不能一句话说出它要干什么。

说不出来，这页就是凑数的，删掉。八页的汇报里有六页能说清，就已经合格了。

还有个小判断：如果一页去掉之后，听众完全察觉不到少了东西，那它本来就不该在。

可以让它替你把关：

```
把我这份大纲的每一页，用一句话概括它想让听众记住什么。
哪一页你概括不出来，单独标出来告诉我。
```

## 让它挑自己的毛病

这招很多人不知道，但非常好用。

```
现在你换个身份，你就是那位总监。
从这份大纲里挑出你最可能当场追问的两个地方，写清楚你会怎么问。
再告诉我，我该在哪一页补上什么数据才能答得上来。
```

它会挑出"你说复购率提升了，但没有对比的基数"这类真问题。领导会问的，往往就是这种。

## 时长决定页数

十分钟的讲话，八页已经算多。一页讲一分钟出头，加上开头结尾，刚好。二十分钟的报告，控制在十五页以内。

页数超了怎么办？让它帮你砍：

```
这份大纲有 14 页，但我只有 10 分钟。
请告诉我哪几页可以合并、哪几页可以直接删，并说明理由。
砍完之后每一页要保留的那一句话，重新给我写一遍。
```

大多数人是反过来的：先憋出一堆内容，再硬往时间里塞，结果讲到一半就被叫停。先定页数，再往上填内容，顺序对了能省很多返工。

## 配图和排版交给专门工具

AI 对话框里产出的是文字。真正的排版、配图、动画，用专门的工具省事得多。现在不少办公套件和在线演示工具都带了 AI 排版功能，把大纲贴进去就能出一版初稿。

好处是文字和版面可以分开改。内容不对改大纲，版面难看换模板，互不干扰。

还有一点要提醒：AI 生成的配图和图表经常是编的，看着很真。凡是放上去的数字，自己核一遍来源。

> 记住这一句：先要大纲，再要内容，第三步要讲稿；哪一页说不出一句核心话，就删掉。
