## 这节课你会...

今天真的打开一个 AI，跟它说上第一句话。就这一件事，别贪多。

## 挑一个就行，别挑花眼

国内能用的有 DeepSeek、豆包、Kimi、通义这些，国外有 ChatGPT。手机应用商店搜一下就有，网页版也能用。

选哪个？**随便挑一个。** 这句话不是敷衍。它们的基础能力差不太多，对刚上手的人来说，用哪一个都比纠结用哪一个强。

注册一般用手机号收个验证码就行，不用花钱。下载 App 和打开网页版都一样，看你哪个顺手。手机打字慢就用电脑，电脑上复制粘贴方便。

## 打开之后你会看到什么

界面都长得很像，就几样东西：

- **中间一个大输入框。** 你把话打在这里。
- **一个发送按钮或者回车键。** 按下去，它开始答。
- **一个"新对话"按钮。** 通常在左上角或右上角，下面单独说它。
- **一列历史记录。** 你之前聊过的都在，点一下能回去接着聊。

就这些。没有需要你设置的参数。

界面上那些你完全看不懂的按钮，先别管。刚开始你只需要用到输入框和发送键，剩下的等用熟了自然就明白。

## 第一句别只打"你好"

很多人第一次打开，打一句"你好"，它回一句"你好，有什么可以帮你的吗"，然后两边就僵住了，觉得这东西也就那样。

问题不在它，在"你好"这句话里没有任何事。**直接派活。** 你想要什么，就说什么。

说得越具体，它答得越有用。这条规矩从第一次对话就成立。

## 五句可以直接复制的开场

懒得想就挑一句，把方括号里的内容换成你自己的，粘进去按发送。

```
我女儿上小学三年级，作文总是写不长，憋半天就三行。
请给我三个在家就能练的小方法，每个说清楚怎么做、每天花几分钟。
```

```
帮我把下面这段话改得客气一点，我要发给房东：
[把你原来写的话粘在这里]
```

```
我要请三天假，理由是家里老人住院。
帮我写一段发给领导的微信，简短、不啰嗦、不要显得在找借口。
```

```
我开了家小超市，想在店门口贴张纸，提醒顾客不要把宠物带进来。
帮我写三个版本：一个客气的，一个直接的，一个带点幽默的。
```

```
我要做红烧排骨，家里只有排骨、土豆、葱姜蒜、生抽和老抽。
给我一个步骤清楚的菜谱，每一步说清楚火候和时间。
```

这五句有个共同点：都交代了背景，都说清了要什么，都提了要求。你照着这个套路改，什么问题都能问。

## 那个"新对话"按钮是干嘛的

它相当于清空桌面，重新开始。

一件事聊完了，去点一下，开始下一件。好处有两个。

一是**它不容易串台**。你前面聊的是给孩子做早餐，接着又问报税的事，它有时候会把两件事搅在一起。
二是**聊天太长它容易犯迷糊**。一段对话拖得很长，它容易忘掉你最早交代过的话。换个新对话重新说一遍背景，它反而清醒。

所以别舍不得点。发现它开始答得不对劲，第一反应就是开个新对话，把要求重新说清楚。

> 记住这一句：第一次对话别客气，直接派活。它不是等你问好的客人，是等你交活的帮手。
