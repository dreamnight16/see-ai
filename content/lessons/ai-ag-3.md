## 这节课你会...

知道"会自己开网页的智能体"现在能干到什么程度，以及怎么盯着它别跑偏。

## 大致分三类，别混着说

这类产品名字挺乱，其实能分三堆。

**通用智能体**，Manus 这类。你给一句话，它自己拆任务、开浏览器、写东西、做表，最后交一个成品给你。

**浏览器智能体**，装在浏览器里，能读你当前这个页面，帮你点按钮、填表单、翻页抓信息。

**能操作电脑的智能体**，看得见你的屏幕，能动鼠标键盘，跨软件干活。比如从邮件里复制一段，粘到表格里。

三类的边界很模糊，产品也在天天变，**以你手上那个为准。** 你只要记住一件事：它们都是"替你在界面里点点点"，不是"替你思考"。

## 一个真实任务，从头到尾长什么样

假设你说："帮我找三个便宜的降噪耳机，做成对比表。"

它拆出来大概是这么几步：

1. 打开电商网站，搜"降噪耳机"，按价格排
2. 挑出前几个，逐个点进去看价格、评价、主要卖点
3. 发现有款缺货，换一个补上
4. 把三个的信息整理成表格
5. 发给你

顺利的话几分钟出结果。你拿着表再判断，比在几十个商品页里翻半小时强。

翻车的样子你也得知道。它可能把"降噪耳机"搜成了"耳机"，把不带降噪的也列进去；可能只抓到原价，没看到券后价；也可能点进一个页面就出不来了，在同一个商品页反复刷新。

**结果看着很整齐，不代表每一步都对。** 表格做得越漂亮，你越要抽查几行。

## 它常卡在哪

三个地方，反反复复。

**登录。** 大部分网站要账号，它没有你的账号，也不该有。有些产品能让你把登录状态给它，但这一步等于把账号的一部分交出去了，得想清楚。

**验证码。** 图片验证、滑块、点选文字，专门用来防机器的，它天然过不去。有的能弹出来让你手动点一下，有的直接卡死。

**网页改版。** 网站换个按钮位置、改个名字，它昨天还会用的招今天就失灵。所以这类产品更新很勤，不是因为功能不够，是外面一直在变。

碰到这三个，别硬等。你上去点两下，比它在那儿试十遍快。

## 盯着它干的正确姿势

第一件事：**先拿小事试。** 别上来就让它去办报销、填报名表。先让它"把这篇文章的标题和作者抓出来"，看它做得怎么样。

第二件事：**看它每一步在干嘛。** 好产品会把它正在做什么显示出来，它是在搜索、在点按钮、还是在写文件，你一眼能看见。看见它往奇怪的方向去了，立刻喊停。

第三件事：**该接管就接管。** 卡在登录或者验证码，你自己弄完再让它继续，比它自己死磕强。

第四件事：让它先给计划。开头加这么一段就够了：

```
这个任务你先别动手。先把计划列出来：
你打算分几步、每步用什么网站、哪一步可能需要我配合。
我确认之后你再开始。卡住的时候停下来问我，不要自己硬试。
```

这句话能省不少返工。它想歪了，你在计划阶段就能看出来。

它跑完交活的时候，再补一句：

```
交结果之前，把这几个说清楚：
1. 哪个数据是你直接从网页上看到的，哪个是你推测的
2. 哪一步你没做成功、用了什么办法绕过去
3. 这份结果里哪一条你最没把握
```

## 什么时候还不如自己动手

有几种情况，你自己上更快。

一是**两三下能点完的事**。你说清需求的功夫，自己已经点完了。

二是**要登录、要填个人信息的事**。你盯着它过验证码，比你自己填还慢。

三是**结果错了代价很大的事**。报名、退款、给老师发邮件，这类宁可自己来。

四是**你自己都不清楚要什么的事**。它拆步骤的前提是你有个明确目标。你自己都没想明白，它会给你一个很像样但完全不对的东西。

反过来，查资料、比价、整理成表、批量重复的点击，这几类它确实省时间。

> 记住这一句：它会点按钮，但它不知道对错。你给的任务越具体，它翻车的空间越小。
