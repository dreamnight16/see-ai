## 这节课你会...

把散落在微信、便签、会议本里的零碎信息，变成一份能直接交上去的报告或公文。

---

## 先给素材，别让它凭空编

很多人打开对话框第一句是"帮我写一份月度工作总结"。这种问法，AI 只能还给你一篇谁都能用的空话。

顺序要反过来：你先把素材倒给它。

素材长什么样？就是你这一个月真实干过的事。比如：

- 跟进客户 17 家，成交 3 家，其中两家是老客户介绍
- 整理了 200 条历史客户资料，发现 40 多条电话是错的
- 给新人做了两次产品知识培训
- 月底物流延迟，收到 4 单投诉

素材从哪来？翻你的聊天记录、工作群、报销单、日程表和便签。花十分钟凑一凑，比对着空白页憋半小时管用。

把这些丢进去，再让它搭结构。它就会把"资料错误率高"归到流程优化，把物流投诉归到风险提醒，而不是硬凑成三条业绩。

```
下面是我这个月干的事，写得比较乱，你先别写正文。
帮我把它们归类成三到四块，每块起一个小标题，并告诉我每块该放哪几条。
等我确认结构之后，你再动笔写。
```

## 周报、通知、请示，问法不一样

周报月报偏"我做了什么、结果如何、下周打算"。

通知公告偏"谁、什么时候、在哪、做什么、找谁问"。这五项缺一项，就会有人跑来问你。

请示偏"为什么要做、需要什么支持、大概多少成本、不做会怎样"。这类文书最忌讳只讲困难不讲方案。

可以直接这样说：

```
请帮我写一则部门内部通知，内容是：本周五下午 3 点在三楼会议室开季度复盘会，
每个组准备 5 分钟发言，带上上季度的数据。
要求两百字以内，开头写清时间地点，结尾写联系人是我，名字写"王莉"。
```

## 一次要三个版本

同一个内容，发给不同的人要用不同语气。别只要一版，让它一次给三份。

```
同一个内容，给我三个版本：
1. 正式版，发给集团领导，用书面语
2. 简短版，两百字以内，发在工作群里
3. 口语版，我在电话里照着说，怎么顺口怎么来
```

你拿到三份挑一份改，比从一份硬改快得多。很多时候你想要的是中间那版，但自己写只会写成第一版。

## 怎么改成你自己的话

AI 写的稿子有个毛病：太整齐，一看就不是你写的。

改的办法是往里加"具体的脏东西"。加一个真实的客户名字，加一个具体到小数点的数字，加一句你当时真实的抱怨。这些 AI 编不出来，只有你有。

还有个小技巧，写完让它反过来问你：

```
这份总结读起来太官方了。你从里面挑出三句最像套话的，
逐句问我在实际情况里对应的是什么事情，我来回答，你再替换掉。
```

## 有些场合别让它代写

检讨书、事故说明、涉及违纪的处理材料，自己写。这类东西一旦被发现是 AI 代写的，性质就变了，不是你文笔的问题。

涉及金额、合同条款、法律责任的公文，AI 可以帮你顺句子，但数字和条款必须你自己逐字核。它会把数字写得很自信，也很可能是错的。

> 记住这一句：AI 帮你搭架子、顺句子，素材得是你自己的，数字得你自己核。
